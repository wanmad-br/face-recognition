# face-recognition

A simple Java application for experimenting with face-recognition workflows using DJL.

## What it does

This starter project demonstrates how to:
- build a Maven-based Java app,
- include DJL and PyTorch support,
- load an image from disk,
- inspect it with DJL and print a small feature summary.
